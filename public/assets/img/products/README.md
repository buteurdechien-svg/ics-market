# Vraies photos de produits

Déposez ici vos photos (vous en avez les droits) nommées d'après le **slug**
du produit, par exemple `nexora-x1-smartphone-128-go-1.jpg`.

Le site utilisera automatiquement la photo si elle existe, sinon l'illustration.

Trouver le slug d'un produit : il apparaît dans l'URL de la fiche, ou via
`SELECT slug FROM products;` en base.

Formats acceptés : .jpg .jpeg .png .webp
